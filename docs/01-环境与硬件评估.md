# 01 · 环境与硬件评估

在安装之前，先搞清楚自己的硬件能跑什么，避免装完发现跑不动白折腾。

## 1. 官方系统要求（参考）

- **CPU**：4 核心及以上（建议 8 核）
- **内存**：8GB 起步，建议 16GB 以上（跑大模型推荐 32GB）
- **显卡**：至少 4GB 显存，建议 8GB 以上（支持 NVIDIA / AMD / Intel / Apple 芯片）
- **硬盘**：至少 20GB 可用空间（不含模型），模型动辄几个 GB 到几十 GB
- **软件**：Python 3.12 / 3.13（推荐 3.13）、Git

> 注意：官方系统要求页面提到，Python 3.13 支持良好、推荐使用；3.14 可用但部分自定义节点可能有问题；3.12 是遇到兼容问题时的稳妥备选。

## 2. 判断你的硬件该走哪条路

打开任务管理器（`Ctrl+Shift+Esc`）→ 性能，查看 CPU / 内存 / GPU。

| 你的情况 | 建议路径 |
|---|---|
| 有 NVIDIA 独立显卡（RTX 系列，显存 ≥ 6GB） | 本地便携版（NVIDIA 版），体验最好 |
| 有 NVIDIA 老显卡（GTX 10 系等） | 本地便携版（CUDA 12.6 版） |
| 只有核显（如 Intel Iris Xe）或 AMD 集显 | 本地 CPU 模式可以跑，但慢；**更推荐直接上云端 GPU** |
| 内存 ≥ 32GB、无独显、想本地折腾 | CPU 模式 + 小模型/小尺寸出图，勉强可用 |
| 想跑 SDXL / Flux 等大模型 | 基本必须要有 8GB+ 显存或上云 |

## 3. 关于“无独显 CPU 直跑”的实话

- 纯 CPU 跑 ComfyUI **可以**，出图成功率没问题，但速度远慢于 GPU（一张 512×512 小图可能需几分钟）。
- 你的机器若有 32GB 内存，可以先把模型加载进内存硬算，但**不要对速度有期待**。
- 结论：无独显且要正经出图/跑工作流 → **用云端 GPU（免费/低价）比本地 CPU 划算得多**，教程见 [06-云端部署](06-云端部署.md)。

## 4. 需要提前装好的小工具

| 工具 | 用途 | 下载 |
|---|---|---|
| 7-Zip | 解压便携版 7z 压缩包 | <https://www.7-zip.org/> |
| Git | 手动安装时克隆仓库 | <https://git-scm.com/> |
| Python 3.13（手动安装时需要） | 运行环境 | <https://www.python.org/downloads/> |
| Microsoft Visual C++ Redistributable | 手动安装的运行时依赖 | 官方页面指引 |

## 5. 本节小结

- **有 N 卡**：直接看 [02-本地安装-便携版](02-本地安装-便携版.md)。
- **无 N 卡**：先看 [06-云端部署](06-云端部署.md)（推荐），想本地折腾再看 02 的 CPU 模式。
- 无论哪条路，Git 和 7-Zip 都建议先装好。
