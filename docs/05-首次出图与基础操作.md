# 05 · 首次出图与基础操作

## 1. 界面长什么样

浏览器打开 `http://127.0.0.1:8188` 后，你会看到一个深色节点画布（Graph 视图）。ComfyUI 的核心理念是**把生成流程拆成一个个节点，用连线串联起来**：从“加载模型”到“文本提示”再到“采样器”最终“保存图片”。

## 2. 加载默认工作流（最快出图路径）

1. 菜单栏点击 **Load Default**（或 `Workflow → Browse Templates` 选模板）。
2. 此时画布会出现一条完整流程：
   - **Load Checkpoint**：加载大模型
   - **CLIP Text Encode（正向/负向提示词）**：写提示词
   - **KSampler**：采样参数（步数、CFG、采样器等）
   - **VAE Decode**：解码
   - **Save Image**：保存图片
3. 在 **Load Checkpoint** 节点上选择你放好的模型（[04-模型管理与下载](04-模型管理与下载.md)）。
4. 在提示词节点里写内容（中文模型不支持中文提示词，请用英文，或使用支持中文的模型/插件）。
5. 点击右侧 **Queue Prompt**（或 `Ctrl+Enter`）开始生成。

## 3. 关键参数速查（KSampler 节点）

| 参数 | 说明 | 建议初值 |
|---|---|---|
| seed | 随机种子，固定后可复现同一张图 | 随机 |
| steps | 采样步数，越多越精细但越慢 | 20~30 |
| cfg | 提示词跟随强度，过高容易过曝/崩 | 6~8 |
| sampler_name | 采样器算法 | euler 或 dpmpp_2m |
| scheduler | 调度器 | karras |
| denoise | 去噪强度，图生图时 <1 | 1.0 |

## 4. 工作流文件（.json）

- **保存工作流**：`Ctrl+S` 或菜单 `Workflow → Save`，会存成 `.json` 文件。
- **加载工作流**：把 `.json` 拖进浏览器窗口即可。
- 分享/复现别人的工作流时，直接给 `.json` 文件，比截图好用得多。

## 5. 安装 ComfyUI-Manager（强烈推荐）

[ComfyUI-Manager](https://github.com/ltdrdata/ComfyUI-Manager) 是最重要的插件，用来搜索安装自定义节点、管理缺失节点、一键补依赖。

手动安装（便携版为例，在 `ComfyUI/custom_nodes/` 下）：

```bash
cd ComfyUI/custom_nodes
git clone https://github.com/ltdrdata/ComfyUI-Manager.git
```

然后**重启 ComfyUI**，界面会多出 Manager 菜单，可从里面搜索安装其它自定义节点（如 ControlNet 套件、放大套件等）。

## 6. 首次出图失败常见原因

- **选不到模型**：模型没放对目录或没刷新，见 [04-模型管理与下载](04-模型管理与下载.md)。
- **报错缺节点/缺依赖**：装了工作流但缺自定义节点 → 用 Manager 一键安装缺失节点。
- **显存不足**：加 `--lowvram`/`--novram` 启动，或降低图片尺寸/步数。
- **太慢（CPU）**：无独显时很慢是正常的，建议云端，见 [06-云端部署](06-云端部署.md)。
