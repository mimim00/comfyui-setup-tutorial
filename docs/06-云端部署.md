# 06 · 云端部署（腾讯云等）

**如果你没有独立显卡（只有核显），云端 GPU 是性价比最高的选择。** 下面以腾讯云为主，给出几种常见方案。

## 1. 方案对比

| 方案 | 适合人群 | 特点 | 成本 |
|---|---|---|---|
| 腾讯云 HAI（高性能应用服务） | 想省事、镜像开箱即用 | 选择 ComfyUI 镜像即可，几分钟起 | 按量/包月，可关机省钱 |
| 腾讯云 CVM GPU 云服务器（GN 系列） | 需要完全自控 | 自己装驱动/CUDA/ComfyUI | 相对贵，需自管理 |
| 腾讯云 云函数 ComfyUI 应用 | 有云开发经验 | GPU 卡型可选 GC49D/T4/L20 | 按调用计费 |
| Cloud Studio（云端开发环境） | 白嫖党、尝鲜 | 提供免费 GPU 工作空间（如 T4 16G 显存） | 免费额度内 0 元 |
| 海外 GPU 云（如 RunPod 等） | 需要大显存 | 24G/32G 显存实例 | 按小时计费 |

> 思路：**先白嫖/低价尝鲜，跑通后按需升级显存**。免费/低价空间不用时一定要关机，避免扣费。

## 2. 腾讯云 HAI 部署（最简单）

1. 登录腾讯云控制台 → **高性能应用服务 HAI**（<https://cloud.tencent.com/>）。
2. 新建应用，**应用镜像选择 ComfyUI**（预装好环境与常用插件）。
3. 选择 GPU 卡型与地域（按显存需求选择，一般 ≥10GB 显存起步，如 T4 / L20 / 更高卡型）。
4. 创建并启动，平台会自动：分配 GPU → 拉取镜像 → 启动 ComfyUI。
5. 创建成功后，**在安全组/防火墙放行 8188 端口**（ComfyUI 默认端口），通过公网地址访问界面。

## 3. 腾讯云 CVM GPU 手动部署（通用流程）

适合 Linux（Ubuntu 20.04/22.04 LTS）GPU 实例，关键步骤：

```bash
# 1. 安装 NVIDIA 驱动 + CUDA
sudo ubuntu-drivers autoinstall
sudo reboot
nvidia-smi              # 重启后确认驱动可用

# 2. 装 Miniconda + Python 虚拟环境
wget https://repo.anaconda.com/miniconda/Miniconda3-latest-Linux-x86_64.sh
bash Miniconda3-latest-Linux-x86_64.sh
conda create -n comfyenv python=3.12 -y
conda activate comfyenv

# 3. 安装对应 CUDA 的 PyTorch（示例 cu126）
pip install torch torchvision torchaudio --index-url https://download.pytorch.org/whl/cu126

# 4. 克隆并安装 ComfyUI
git clone https://github.com/Comfy-Org/ComfyUI.git
cd ComfyUI
pip install -r requirements.txt

# 5. 监听所有网卡启动，供外部访问
python main.py --listen 0.0.0.0 --port 8188
```

然后：
- 在云控制台**安全组放行 8188 端口**。
- 浏览器访问 `http://服务器公网IP:8188`。

> 安全提示：`--listen 0.0.0.0` 会让任何人都能访问，建议配合防火墙只放行你的 IP，或用 SSH 隧道访问。

## 4. 云函数 ComfyUI 应用（进阶）

在腾讯云 云函数（SCF）控制台搜索“ComfyUI”应用模板，按指引选择 GPU 卡型（图像生产推荐 GC49D，也可选 T4/L20）与地域，创建后按文档完成端口映射（通常 5000 或 8188 端口对外暴露）即可访问。

## 5. 云端 vs 本地（无独显用户怎么选）

| 维度 | 本地 CPU | 云端 GPU |
|---|---|---|
| 出图速度 | 慢（几分钟/张） | 快（几秒~十几秒/张） |
| 模型支持 | 受内存限制 | 大显存可跑 SDXL/Flux |
| 成本 | 电费+时间 | 按量付费（可关机省钱） |
| 隐私 | 数据在本地 | 数据在云端 |

**建议**：先跑通云端免费额度，觉得顺手再决定是否升级显存；本地保留一个便携版用于简单测试。
