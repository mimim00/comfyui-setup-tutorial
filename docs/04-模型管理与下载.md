# 04 · 模型管理与下载

ComfyUI 出图靠“模型”。模型文件要放进**对应目录**才能被识别。刚装好时模型是空的，界面里选不到任何模型，这是正常的。

## 1. 模型目录结构

在 ComfyUI 根目录下的 `models/` 文件夹中：

```
models/
├── checkpoints/         # 大模型（SD1.5 / SDXL / Flux 等，.safetensors）
├── diffusion_models/    # 扩散模型（Flux 的 UNet 等）
├── clip/                # CLIP 文本编码器
├── clip_vision/         # CLIP Vision（图生图、Reference 等用）
├── loras/               # LoRA 小模型
├── vae/                 # VAE（图像解码器）
├── controlnet/          # ControlNet 控制模型
├── embeddings/          # Embedding（Textual Inversion）
├── upscale_models/      # 放大模型（ESRGAN / SwinIR 等）
└── configs/             # 配置文件
```

> 便携版里模型目录在 `ComfyUI_windows_portable\ComfyUI\models\`。
> 桌面版/便携版可以在界面 `Help → Open Folder → Open Models Folder` 直接打开。

## 2. 常见模型类型速查

| 类型 | 放哪 | 说明 |
|---|---|---|
| Checkpoint 大模型 | `models/checkpoints/` | 最常用，决定画风与底模 |
| LoRA | `models/loras/` | 微调风格/角色/物体 |
| VAE | `models/vae/` | 色彩与细节解码，常随大模型附带 |
| ControlNet | `models/controlnet/` | 姿态、线稿、深度等条件控制 |
| Embedding | `models/embeddings/` | 负向提示词等小向量 |

## 3. 去哪里下载模型

- **官方推荐站点**：CivitAI（<https://civitai.com/>），模型类型全、质量高，支持按类型筛选。
- **Hugging Face**（<https://huggingface.co/>）：官方/社区底模、SDXL、Flux 等。
- **国内网络慢**：可用 Hugging Face 镜像 `hf-mirror.com` 加速下载（在下载命令前加 `HF_ENDPOINT=https://hf-mirror.com`）。
- **ComfyUI 官方示例模型**：官方文档“进行第一次图片生成”中有指引。

> 版权与许可：下载模型前注意查看该模型的 License，商用需确认是否允许。

## 4. 模型放好之后

- 把 `.safetensors` / `.ckpt` 等文件放进对应目录后，**需要在 ComfyUI 界面刷新/重启**才能看到。
- 便携版重启：关闭命令行窗口 → 重新双击 `run_*.bat`。
- 也可以在界面的模型选择下拉框中点击刷新按钮。

## 5. 外部模型路径（进阶）

模型不想放默认目录时，用 `extra_model_paths.yaml` 指向外部文件夹（配置方法见 [03-手动安装-进阶](03-手动安装-进阶.md) 第 7 节）。适合：
- 多个 ComfyUI 实例共享模型，省磁盘
- 与 Stable Diffusion WebUI 共用模型文件

## 6. 模型下载加速技巧

- 使用 **CivitAI** 或 **Hugging Face** 的下载工具/镜像。
- 大模型动辄 2~7GB，建议用支持断点续传的下载器。
- 核对文件哈希（`.md5`/`.sha256`）避免下载损坏导致加载失败。
