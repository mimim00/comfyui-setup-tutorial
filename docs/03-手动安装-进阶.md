# 03 · 手动安装（进阶）

适合想深度定制、二次开发或需要自己控制 Python 环境的人。手动安装的官方流程是：**建虚拟环境 → 克隆仓库 → 装依赖 → 启动**。

> 想省事直接用 [02-本地安装-便携版](02-本地安装-便携版.md) 即可，本页是进阶路线。

## 1. 前置条件

- 已安装 **Git**
- 已安装 **Python 3.13**（推荐；3.12 亦可作备选）
- 已安装 **Microsoft Visual C++ Redistributable**（官网指引处可下载）

## 2. 创建虚拟环境（推荐用 Miniconda）

避免 ComfyUI 的依赖污染系统级 Python 环境。

```bash
conda create -n comfyenv
conda activate comfyenv
```

> 不使用 conda 的话，也可以用 Python 自带的 venv：
> ```bash
> python -m venv comfyenv
> comfyenv\Scripts\activate   # Windows
> ```

## 3. 克隆仓库

```bash
git clone https://github.com/Comfy-Org/ComfyUI.git
cd ComfyUI
```

## 4. 安装 GPU 依赖（PyTorch）

**NVIDIA（CUDA 13.0，对应 Python 3.13）：**

```bash
pip install torch torchvision torchaudio --extra-index-url https://download.pytorch.org/whl/cu130
```

**NVIDIA（更早显卡 / CUDA 12.x）可参考官方指引选择对应 cu 版本。**

**AMD（ROCm）：**

```bash
pip3 install torch torchvision torchaudio --index-url https://download.pytorch.org/whl/rocm7.2
```

**纯 CPU（无独显）：**

```bash
pip install torch torchvision torchaudio
```

> 确认是 CPU 版：`pip show torch` 应看到 CPU 版本；启动时加 `--cpu` 参数。

## 5. 安装 ComfyUI 依赖并启动

```bash
pip install -r requirements.txt
python main.py
```

看到 `To see the GUI go to: http://127.0.0.1:8188` 即启动成功，浏览器访问该地址。

常用启动参数：

| 参数 | 作用 |
|---|---|
| `--cpu` | 强制使用 CPU |
| `--listen 0.0.0.0` | 局域网可访问 |
| `--port 8189` | 修改端口（端口被占用时用） |
| `--lowvram` / `--novram` | 低显存优化模式 |
| `--force-fp16` | 强制半精度，降低显存/内存占用 |

完整参数见：`python main.py --help`。

## 6. 更新 ComfyUI

```bash
# 进入 ComfyUI 安装路径，且确保当前在虚拟环境中
git pull
pip install -r requirements.txt
```

> 注意：必须在虚拟环境内执行，否则依赖会装到系统 Python 里。

## 7. 添加外部模型路径（可选）

如果想把模型放在 ComfyUI 默认目录之外（例如多个实例共享模型、或与 WebUI 共用），使用 `extra_model_paths.yaml`：

1. 复制根目录示例文件：`ComfyUI/extra_model_paths.yaml.example` → `extra_model_paths.yaml`
2. 修改为你的模型路径，示例：

```yaml
my_custom_config:
  base_path: D:/AI/models
  checkpoints: checkpoints
  loras: loras
  vae: vae
  controlnet: controlnet
  embeddings: embeddings
```

3. 保存后**重启 ComfyUI** 生效。
