# 02 · 本地安装 · 便携版（解压即用，推荐）

官方便携版（Portable）是封装完整的 ComfyUI Windows 版本，内置了独立的 Python（`python_embeded`）和 CUDA 构建，**解压即可用，无需手动配置 Python 环境**。这是新手最不容易出错的方式。

## 1. 下载

打开 ComfyUI 官方 GitHub Releases 页面：

> <https://github.com/Comfy-Org/ComfyUI/releases>

根据你的显卡类型选择对应安装包：

| 安装包 | 适用显卡 | 内置环境 |
|---|---|---|
| `ComfyUI_windows_portable_nvidia.7z`（CUDA 13.0 版） | 现代 NVIDIA 显卡（RTX 系列） | Python 3.13 + CUDA 13.0 |
| `ComfyUI_windows_portable_nvidia.7z`（CUDA 12.6 版） | NVIDIA 10 系列及更早显卡 | Python 3.12 + CUDA 12.6 |
| `ComfyUI_windows_portable_amd.7z` | AMD 显卡（ROCm） | 内置环境 |
| `ComfyUI_windows_portable_intel.7z` | Intel 显卡 | 内置环境 |
| CPU 版（无 GPU 时使用） | 任意（纯 CPU） | 内置环境 |

> 无独立显卡（只有核显）时，可下载 CPU 版或使用 NVIDIA 版中的 `run_cpu.bat`，但速度很慢，见 [06-云端部署](06-云端部署.md)。

## 2. 解压

用 **7-Zip** 解压下载的 `.7z` 文件。建议解压到**无中文、无空格的路径**（如 `D:\AI\ComfyUI_windows_portable`），避免后续模型读取报错。

解压后目录结构如下：

```
ComfyUI_windows_portable
├── ComfyUI                # ComfyUI 程序主体
├── python_embeded         # 内置的独立 Python 环境
├── update                 # 便携版升级脚本
├── README_VERY_IMPORTANT.txt
├── run_cpu.bat            # 双击启动（仅 CPU）
└── run_nvidia_gpu.bat     # 双击启动（NVIDIA 显卡）
```

## 3. 启动

- NVIDIA 显卡：双击 `run_nvidia_gpu.bat`
- 无独显 / 纯 CPU：双击 `run_cpu.bat`

看到命令行输出类似：

```
To see the GUI go to: http://127.0.0.1:8188
```

说明服务启动成功。正常情况下浏览器会自动打开 `http://127.0.0.1:8188`；如果没有自动打开，手动在浏览器输入该地址即可。

> **重要**：启动后不要关闭那个命令行窗口，关闭窗口 = 关闭 ComfyUI。

## 4. 首次运行会做什么

- 首次启动会下载少量依赖并初始化，稍等即可。
- 进入页面后是一个空的工作流（黑底节点界面），需要先加载模型才能出图，见 [04-模型管理与下载](04-模型管理与下载.md) 和 [05-首次出图与基础操作](05-首次出图与基础操作.md)。

## 5. 更新（升级）

打开 `update` 文件夹，按需双击：

| 脚本 | 作用 |
|---|---|
| `update_comfyui.bat` | 更新到最新 Commit 版本 |
| `update_comfyui_stable.bat` | 更新到最新 stable 稳定版 |
| `update_comfyui_and_python_dependencies.bat` | 更新 ComfyUI 及其 Python 依赖（仅当运行环境出问题时用） |

## 6. 局域网访问（可选）

想让同一局域网内其它设备也能访问，用记事本编辑对应的 `.bat`（如 `run_nvidia_gpu.bat`），在启动命令里加 `--listen`：

```
python_embeded\python.exe -s ComfyUI\main.py --windows-standalone-build --listen 0.0.0.0
```

- `--listen 0.0.0.0`：监听所有网卡，局域网内其它设备通过 `http://本机IP:8188` 访问。
- 注意：开放到局域网有安全风险，仅在自己可信网络中使用。

## 7. 便携版小结

1. 下载对应显卡的 `.7z`
2. 7-Zip 解压到无中文路径
3. 双击 `run_nvidia_gpu.bat` / `run_cpu.bat`
4. 浏览器打开 `http://127.0.0.1:8188`
