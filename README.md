# ComfyUI 搭建教程（开源）

> 一份面向新手的 ComfyUI 全流程搭建教程：从硬件评估、Windows 本地安装（便携版 / 手动版）、模型管理，到云端（腾讯云等）部署与常见问题排查。持续维护，欢迎 Star / PR。

ComfyUI 是一个开源、模块化的 Stable Diffusion 图形化工作流工具，通过“节点连线”的方式灵活组合模型与算法。本教程覆盖本地与云端两条路径，并针对**无独立显卡的 CPU 笔记本**（如 i5-13500H + 核显 + 32GB 内存）给出了切实可行的方案。

---

## 为什么选择 ComfyUI

- **免费开源**：GitHub 上完全开源，无使用限制
- **灵活可控**：节点式工作流，支持 SD1.5 / SDXL / Flux 等多种模型
- **性能好**：对显存占用做了大量优化，低配机器也能跑
- **生态丰富**：大量自定义节点（ComfyUI-Manager 等）可持续扩展
